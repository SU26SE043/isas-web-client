# Learning Roadmap

BRD: FR learning roadmap; `docs/product/product-scope.md` §4.2.

## Purpose

Personalized learning path for Candidates, generated by AI from:

- Target **domain**
- Completed **Interview Practice** reports (same domain)
- Desired **target level**

Roadmap is **not** created from the Learning Hub (`/candidate/learning`).

## Entry

Menu **Roadmap** → `/candidate/roadmap` opens the **Roadmap Creation Wizard** immediately.

After successful create, navigate to **Learning** (`/candidate/learning`) dashboard — do not stay on the wizard. Detail study UX: [`learning.md`](./learning.md).

## Creation wizard

| Step | Screen | Rules |
| --- | --- | --- |
| 1 | Choose domain | **Frontend**, **Backend**, **Business Analyst** only; Next disabled until selected |
| 2 | Choose interview reports | Up to **3** completed reports for that domain (newest first); multi-select + Select all / Unselect all |
| 3 | Target level | Intern, Fresher, Junior, Middle, Senior, Lead |
| 4 | Confirm | Domain, target level, report count + selected list; Back / Create Roadmap |
| 5 | AI generate | On Create: analyze reports → strengths/weaknesses → skill gaps → path, milestones, lessons, practice sessions → redirect Learning |

### Step 2 — report row fields

- Interview name
- Interview date
- Overall score
- Level
- Duration
- Status

### Step 2 — empty state

If the domain has **no** completed reports (or fewer than **3**):

> Bạn chưa có Interview Report thuộc Domain này. Hãy hoàn thành ít nhất 3 buổi Luyện phỏng vấn để tạo Roadmap.

Next is disabled. Candidate cannot skip steps.

## Business rules

- Only **completed** Interview Practice reports may be used.
- Reports from other domains must not appear.
- Multi-select, Select all, Unselect all required.
- No step skipping; Back/Next between wizard steps.
- Cannot create without valid report selection (≥1 selected and domain has ≥3 eligible reports).
- Success → `/candidate/learning`.
- Learning Hub remains a separate catalog (T3); it does not host creation.
